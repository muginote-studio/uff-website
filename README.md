# Uff — homepage design proposal

A standalone static homepage concept for Uff Boulangerie & Café.

## GitHub Pages

Upload this directory to the root of a new repository. In Settings → Pages, select Deploy from a branch, then main and / (root). No build step or dependencies are required.

All asset paths are relative, so both a project URL and a custom domain are supported.

## Content

This is an unofficial proposal. Photography is illustrative stock imagery, and the shop drawing is conceptual. Replace photography with approved store photographs before using this as the official shop website.
